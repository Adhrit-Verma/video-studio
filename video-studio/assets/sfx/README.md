# Sound effects (all CC0, public domain)

- `casino/`, `impact/`, `interface/`, `ui/`: [Kenney](https://kenney.nl/) audio packs, CC0.
- `keyboard/keypress-001..032.wav`: [Keyboard Soundpack #1](https://opengameart.org/content/keyboard-soundpack-1-typing-and-single-keystrokes)
  by unicae_games, CC0.
- `sfx-analysis.md` / `.json`: per-file brightness, high-frequency risk, envelope and
  suggested uses. The analysis and the curated library come from
  [latent-spaces/brag](https://github.com/latent-spaces/brag) (MIT).

Copy only the files a video uses into its `public/sfx/<family>/`, then place them with
the kit's `<Sfx>`. How to choose them is covered in `references/sound.md` → "Sound effects".
